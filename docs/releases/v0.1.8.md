# Books Exporter v0.1.8

状态：已发布（unsigned，build 9）。

> **历史记录，命名规则已变更。** 这一版是 AppKit GUI 独立编号的时期，与 Rust CLI 的
> 版本号互不相干，也是 AppKit 版本占用了 `v*` 命名空间（CLI 侧当时是 `0.3.x`）的
> 产物。此后版本号统一以 `Cargo.toml` 为唯一来源，`v*` tag 必须与它一致。
> AppKit 打包脚本 `appkit/Scripts/package-dmg.sh` 已支持用 `APP_VERSION` 环境变量
> 注入 `CFBundleShortVersionString`，但**发布流水线目前还没有传入它**——当前发布的
> 产物仍然只有 Rust CLI。见根 `README.md` 的「发布」。

## Share Card 编辑器

- 选中 Apple Books 标注后可从详情行进入编辑器，默认立即生成可预览卡片。
- 支持自动/固定字号、水平/垂直对齐、11 款随应用分发字体和 12 个完整模板。
- 长正文、长笔记和中英文混排形成连续的 1200×1600 PNG 页面，不截断内容；笔记沿用正文颜色，并以轻微斜体和细分割线区分。
- 大预览、当前页页码和有边界缩略图带共享同一组分页与渲染结果。
- 保存全部页面；复制默认当前页并提供复制全部页面；AirDrop 发送当前页临时 PNG。
- 移除泛用 macOS 分享面板；编辑卡片不会改写原始 Apple Books 标注。

```bash

./Scripts/package-dmg.sh
```
