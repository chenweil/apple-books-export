# AppKit 分享卡片编辑器迭代规格

状态：已确认，待实现

## Problem Statement

当前 AppKit 分享卡片已经能够从 Apple Books 标注生成图片，但编辑体验仍以单页、固定排版和单一操作路径为中心，无法覆盖长文本、个性化排版和多模板创作的实际需求：

- 长高亮或笔记可能超过单张图片的可读范围；当前预览不能让用户确认所有页面，保存行为却可能已经导出多页。
- 字体虽然可以切换，但字号、水平对齐、垂直对齐以及文字与笔记的层级关系不够明确。
- 主题和背景的视觉变化不够系统，文字颜色没有随着模板变化，模板的安全区域也没有成为可验证的契约。
- “换一换”与分享操作容易受内容长度影响，窗口布局需要保持稳定；泛用系统分享面板也不符合当前“复制当前页、复制全部、隔空投送当前页”的明确操作需求。
- 参考了 Retro Card 的批量预览表达方式后，需要在原生 AppKit 交互中提供类似的多页可见性，同时保持现有应用的操作思维和导出能力。

如果不先固定这些边界，后续新增主题、背景和字体选项会继续扩大渲染与交互的不一致，用户也无法判断最终分享的是哪一页或哪一种排版。

## Solution

将分享卡片定义为固定尺寸的卡片序列：每页保持 1200 x 1600、3:4 比例；短文本仍输出单页，超长正文或笔记按同一套排版规则分页。自动字号达到最小可读字号后也分页，固定字号不缩小、不截断。首页笔记使用笔记区域，笔记溢出后的续页使用完整文字安全区域，避免生成只有少量文字的大量空白页。编辑器提供大预览与受边界约束的缩略图栏，用户可以选择当前页并明确执行“保存全部”“复制当前页”“复制全部”或“隔空投送当前页”。

模板是“单张背景 + 单套配色”的原子组合，负责装饰、文字安全区域和归因区域；用户排版负责字体、字号模式与对齐方式。切换主题或“换一换”只替换模板，不重置用户已选择的字体、字号和对齐方式。默认模板使用接近黑色的高可读文字，并提供若干与背景匹配且经过对比度验证的完整配色模板。12 个模板按固定顺序轮换，每次从游标之后取 4 个并跳过当前模板，游标前进 4 位后保留。

背景资源使用本地、原创的风格化素材：参考用户提供的纸张、旧印刷、柔和水彩、线稿和便签质感，但不复制参考图的像素、文字、具体构图或第三方素材。背景候选以缩略图面板展示，采用可预测的四张轮换候选，避免窗口因内容或候选数量无限增长。

## User Stories

1. 作为读者，我希望打开标注时立即得到一张可读的默认卡片，以便不调整任何设置也能完成分享。
2. 作为读者，我希望默认字号自动适配卡片安全区域，以便短文本保持舒适的视觉层级。
3. 作为读者，我希望选择固定字号，以便在不同卡片之间保持一致的文字尺度。
4. 作为读者，我希望固定字号或自动字号达到最小可读字号后放不下全文时自动分页，而不是截断、溢出或缩小到不可读，以便完整表达原文。
5. 作为读者，我希望长文本显示为多页预览，以便在保存或复制前确认完整内容。
6. 作为读者，我希望看到大尺寸当前页和边界明确的缩略图列表，以便快速判断页面顺序和当前选择。
7. 作为读者，我希望点击缩略图切换当前页，以便只对需要的页面执行复制或隔空投送。
8. 作为读者，我希望保存操作导出全部页面，以便不会因为只看到了当前页而漏保存后续内容。
9. 作为读者，我希望默认复制当前页，以便快速分享当前正在检查的页面。
10. 作为读者，我希望通过一个明确的菜单复制全部页面，以便在需要时一次获得完整卡片序列。
11. 作为读者，我希望隔空投送发送当前页，以便把当前确认过的图片发送到附近设备。
12. 作为读者，我希望不再看到泛用系统分享面板，以便操作结果与“当前页/全部页面”的语义一致。
13. 作为读者，我希望在“分享”原来的位置找到隔空投送操作，以便不需要重新学习按钮位置。
14. 作为读者，我希望看到主题的缩略图和名称，以便通过视觉而不是猜测来选择模板。
15. 作为读者，我希望有 12 张风格统一但各自独立的背景候选，以便获得更多创作选择。
16. 作为读者，我希望默认使用接近黑色的文字配色，以便在浅色背景上保持稳定的可读性。
17. 作为读者，我希望其他配色方案随模板提供，而不是自由输入任意颜色，以便作品保持协调并减少低对比度组合。
18. 作为读者，我希望切换主题时字体、字号和对齐方式保持不变，以便只改变视觉模板而不丢失排版偏好。
19. 作为读者，我希望点击“换一换”时看到四张可预测轮换的完整卡片，以便比较候选而不改变已设置的文字。
20. 作为读者，我希望“换一换”不会让编辑窗口变大或把关闭、完成按钮推到屏幕外，以便任何时候都能退出编辑。
21. 作为读者，我希望设置文字水平左对齐、居中或右对齐，以便适配不同背景的构图。
22. 作为读者，我希望设置文字垂直靠上、居中或靠下，以便调整留白和视觉重心。
23. 作为读者，我希望笔记继承正文的字体、配色和对齐方式，并按 `max(30, 正文字号 × 0.6)` 使用更小的层级，以便正文和笔记看起来属于同一张卡片。
24. 作为读者，我希望署名和来源信息保持模板规定的位置，以便它不会因为正文长度遮挡正文或被裁切。
25. 作为读者，我希望在字体列表中选择现有的内置字体，以便继续使用应用已经提供的字体资源。
26. 作为读者，我希望切换字体后分页和预览立即更新，以便确认字体对页面数量和可读性的影响。
27. 作为读者，我希望背景为文字和笔记预留安全区域，以便装饰不会破坏阅读。
28. 作为读者，我希望每个模板的文字颜色经过对比度验证，以便在不同背景纹理上都能读清楚。
29. 作为读者，我希望导出的每张图片都保持固定 1200 x 1600 尺寸，以便不同分享渠道获得一致结果。
30. 作为读者，我希望编辑器在小屏幕或长文本下仍保持可操作，以便缩略图、操作栏和完成按钮不会互相覆盖。
31. 作为读者，我希望模板切换不会修改原始 Apple Books 标注，以便卡片编辑是可逆的展示操作。
32. 作为读者，我希望生成的卡片文件命名和现有导出规则保持稳定，以便能在文件系统中识别同一组卡片。
33. 作为读者，我希望候选模板和页面的选择状态清晰可见，以便键盘或鼠标操作后不会误以为仍在上一页。
34. 作为维护者，我希望服务层用公开行为覆盖渲染、分页和导出，以便后续新增模板时不会依赖私有视图控制器状态。
35. 作为维护者，我希望 UI 验证只观察用户可见的 AppKit 行为，以便布局调整不会迫使测试绑定内部实现细节。

## Implementation Decisions

### 领域模型与公共边界

- 以 `ShareCardService` 作为生成、分页、预览和导出的公共行为边界。编辑器只负责收集用户选择和呈现结果，不自行复制分页或文字测量规则。
- 将用户排版选择建模为独立值：字体、自动或固定字号、固定字号值、水平对齐和垂直对齐。默认值必须延续现有卡片的可读行为。
- 将行高固定为字号的 1.4 倍，并由测量、分页和绘制共用同一个属性构造，避免不同排版引擎产生页数或裁切差异。
- 将笔记字号定义为 `max(30, primaryFontSize × 0.6)`；笔记首页使用 note area，纯笔记续页使用完整 text-safe area。
- 将模板元数据建模为完整契约：背景、正文和笔记配色、文字安全区域、署名区域以及必要的装饰层。模板选择不拥有用户排版选择。
- 模板为背景与配色的一对一原子组合；候选按规范顺序和持久游标轮换，移除旧 variant 安全区机制。
- 保持 `ShareCard` 与原始 `Annotation` 的边界；生成卡片只能读取标注，不能回写、改写或补全 Apple Books 数据。

### 页面与渲染

- 卡片画布固定为 1200 x 1600；不新增图片尺寸选择器，也不在导出前按用户窗口大小缩放画布。
- 自动字号在模板安全区域内求解；达到最小可读字号后继续分页。固定字号只影响分页，不允许通过截断或越过安全区域来强行塞入全文。用户排版字号在服务层有明确上下限。
- 预览、复制、隔空投送和保存全部使用同一个分页与渲染结果，避免“预览一页、导出多页”产生不同内容。AirDrop 当前页在临时目录生成命名稳定的 PNG，不依赖先保存。
- 页面序号和缩略图属于编辑器状态，不写入卡片正文，除非现有导出规则另有要求。
- 正文、笔记和署名使用明确的层级：笔记继承正文的字体、颜色和对齐方式但按比例缩小；署名使用模板定义的位置和样式。

### 模板、背景与配色

- 保留现有背景资产，并增加 6 张原创风格化背景，总数为 12 张。每张背景必须适配 3:4 画布并经过文字安全区域与对比度检查。
- 背景只借鉴纸张质感、旧印刷、水彩晕染、线稿、便签和拼贴等视觉方向；不得复制用户参考图的文字、像素、具体布局或第三方资产。
- 默认模板采用接近黑色的文字。其他配色作为模板的一部分提供，优先使用深色、高对比度、与背景相容的完整组合，不提供无约束的颜色选择器。
- “换一换”展示 4 张完整候选卡片：从 12 个模板的固定规范顺序中按持久游标取候选，跳过当前模板，每次点击游标前进 4 位并取模。换模板时保留字体、字号模式、字号值、水平对齐和垂直对齐。
- 主题和背景面板必须有稳定的最大尺寸或滚动边界；新增候选不得推动编辑器窗口无限增长。

### 编辑器交互与操作

- 编辑器采用大预览加缩略图栏的结构。当前页始终有明确选中状态，缩略图数量增加时仅在内部滚动。
- 字体、字号、水平对齐和垂直对齐属于编辑状态，并在调整后重新生成页面和缩略图。
- 主操作为保存全部页面。复制按钮默认复制当前页，并提供复制全部页面的菜单项。
- 去掉泛用的 `NSSharingServicePicker` 分享路径；保留原分享位置作为隔空投送当前页的入口，直接生成临时 PNG，不要求先保存；AirDrop 不可用时按钮保持位置但禁用。
- 完成/关闭入口在所有内容长度、候选数量和窗口尺寸下保持可见。窗口使用稳定的最小与最大边界，不能由长文本的 intrinsic size 直接撑大。
- 交互标签需要能表达“当前页”和“全部页面”的范围；主题、页面、复制菜单和隔空投送入口要具备可观察的名称和选中状态。

### 兼容与交付

- 保留现有 1200 x 1600 输出尺寸、默认字体行为、导出目录和文件命名的兼容约束；没有明确要求的既有调用方不应改变语义。
- 现有卡片生成和导出能力先扩展公共模型，再接入编辑器，避免 UI 先实现一套与服务层不同的分页逻辑。
- 该迭代以当前 v0.1.7 为基线，完成实现、验证和文档后再确定下一个版本号；不把 v0.1.7 的发布内容重新定义为本迭代。

## Testing Decisions

测试优先覆盖公开行为，不测试私有生命周期、私有布局计算或具体控件层级。

### 服务层行为

- 验证默认卡片仍可生成，画布始终为 1200 x 1600。
- 验证自动字号在短文本和长文本上可读，达到最小可读字号后仍会分页；固定字号会产生完整的多页序列，任何页面都没有被静默截断。
- 验证水平和垂直对齐会反映在生成结果中，笔记使用继承的字体、配色和对齐层级，笔记续页使用正文安全区，署名落在模板契约区域。
- 验证行高为字号的 1.4 倍，且测量、分页和绘制使用同一排版属性。
- 验证 12 张背景和所有模板配色都能生成，输出具有预期的安全区域和可读对比度。
- 验证切换模板或候选后用户排版选择保持不变，候选轮换顺序稳定且不会重复破坏当前页状态。
- 验证预览页、当前页复制、全部页复制、隔空投送输入和保存全部页面使用同一组页面内容；导出文件数量、尺寸和命名符合约定。
- 验证设置变化导致页数减少时，当前页有效则保留，否则钳制到末页；AirDrop 不需要先完成保存。
- 验证生成过程不会改变输入 `Annotation`。

### AppKit 可见行为

- 验证主题缩略图、背景候选、多页大预览和缩略图栏可见且在边界内布局。
- 验证固定字号长文本下页面数量增加时，编辑窗口不会无限增大，完成/关闭入口仍可见。
- 验证复制当前页与复制全部页面的操作范围，隔空投送位于原分享位置，泛用系统分享面板不再出现。
- 验证“换一换”保留字体、字号和对齐设置，并展示四张可预测候选。
- 验证控件具有稳定、可观察的名称和选中状态，基础键盘操作和关闭路径可用。

### 验证方式

- 使用现有的服务层测试入口验证生成结果和导出结果。
- 使用现有的 AppKit UI 验证入口观察真实窗口行为，不把测试绑定到私有实现细节。
- 对代表性短文本、恰好一页文本、跨页文本、极长文本和中英文混排进行生成图片的视觉检查，重点检查安全区域、对比度、分页连续性和裁切。
- 在完整验证中运行项目已有的 Swift 测试与 UI 验证；任何因环境权限或缺少真实 GUI 而未执行的检查必须在交付记录中明确说明。

## Out of Scope

- 改变卡片画布比例、导出尺寸或引入用户可选的图片尺寸。
- 提供自由颜色选择器、渐变编辑器或逐字上色。
- 运行时从网络下载、生成或替换背景图片；本迭代只接入随应用发布的本地原创资源。
- 复制参考图片的像素、文字、构图或第三方素材。
- 保留或扩展泛用 macOS 分享面板、微信分享入口或其他未定义分享渠道。
- 修改、同步回写或清理 Apple Books 的原始高亮和笔记。
- 新增字体资源；沿用现有字体目录和字体切换能力。
- 把卡片编辑能力扩展到 Web、批量 Excel 工作流或独立的跨平台编辑器。
- 增加 LLM API、自动续写、摘要、解释或内容改写能力。
- 在本迭代中重新发布 v0.1.7；版本升级与发布应在实现和验证完成后单独收口。

## Further Notes

### 实现顺序

1. 扩展服务层模型，固定用户排版、模板契约和分页结果的公共边界。
2. 重构渲染与分页，让预览、复制、隔空投送和保存共享同一结果。
3. 加入 12 张背景、模板配色、安全区域和原创资源说明，并完成视觉检查。
4. 重做编辑器的多页预览、缩略图、字体/字号/对齐控制、候选模板和稳定窗口布局。
5. 收口复制、全部复制、保存全部、隔空投送、测试、文档和下一版本发布。
