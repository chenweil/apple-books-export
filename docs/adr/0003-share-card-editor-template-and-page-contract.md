# ADR 0003: Share Card 编辑器分离模板视觉与用户排版

- 状态: 已接受
- 日期: 2026-08-05

Share Card 继续使用固定的 1200×1600、3:4 画布；Card Template 是一个绑定单张背景和单套配色的原子组合，另负责装饰、文字安全区和归因区域。用户排版负责字体、字号模式、字号值以及水平/垂直对齐。选择“换一换”或主题缩略图时只更换模板视觉，不覆盖用户排版，从而让长文分页、候选模板和即时预览保持可预测。旧的 variant 安全区机制不属于新的模板契约。

长文本形成 Card Sequence。自动字号达到最小可读字号后同样分页；固定字号不缩小、不截断。行高固定为字号的 1.4 倍，并由测量、分页和绘制共用。补充笔记在承载正文的页面使用 note area，溢出后在续页使用完整 text-safe area，字号为 `max(30, primaryFontSize × 0.6)`。编辑器使用一张大预览和有边界的缩略图带，保存写出全部页面，复制默认作用于当前选中页，AirDrop 为当前页生成临时 PNG 后发送且不要求先保存；通用系统分享面板从该界面移除。背景资源可以根据参考图的视觉语言制作原创素材，但不直接复用参考图片的像素、文字或构图。

## Consequences

- `ShareCardService` 需要在同一个公共 seam 中使用模板安全区和用户排版计算字号、分页、颜色和渲染，避免预览与导出分叉。
- 每个模板必须声明正文安全区和归因区域；新增背景需要通过对比度和长文布局验证。
- 模板候选按固定的十二项规范顺序轮换；每次从持久游标之后取四项并跳过当前模板，游标前进四位后保留，选择候选不重置游标。
- 编辑器的候选区、缩略图带和主题面板必须有固定尺寸或滚动边界，不能因页数或候选数量撑大窗口。
- 复制、保存、AirDrop 的页面范围需要分别测试，不能用“多张图片写入剪贴板”代替当前页默认行为。
- 设置变化导致页数减少时，当前页索引在有效范围内保持，否则钳制到最后一页。
