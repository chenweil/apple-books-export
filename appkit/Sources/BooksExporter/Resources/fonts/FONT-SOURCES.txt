# Share Card Font Sources

The files in this directory are bundled only for the Share Card renderer. The
font files were retrieved and checked on 2026-08-04. Re-check the linked terms
before making a public release, especially for fonts without a standard open
source license.

The four publisher-statement fonts above are bundled based on the publisher
statements linked above. Those statements are not replaced by this note or by
the aggregator that helped locate the files. Do not sell those font files
separately, modify them, or claim a broader license than the original source
grants.

The four Huiwen fonts are bundled based on the user-provided statement
transcribed in `HUIWEN-NOTICE.txt`. That statement forbids selling the fonts
separately or as part of a resource package for profit, while allowing
forwarding, copying, modification, and derivative versions. It does not grant
any rights beyond the statement supplied with these files.

The LXGW WenKai font is bundled unmodified with the complete OFL 1.1 text and
the upstream reserved-name notice. Any modified or derivative font must follow
the OFL 1.1 terms and the upstream naming restrictions.

## Not bundled pending authorization

- `手书体`: the [ZCOOL work page](https://www.zcool.com.cn/work/ZMjI2MDk1MDg=.html)
  currently exposes attachment metadata saying authorization is unclear.
- `锐字真言体`: the [publisher page](http://reeji.com/font/rui_zi_zhen_yan_ti/)
  is listed as free for commercial use **with authorization required**.

These two fonts can be added after the author or publisher provides permission
that covers bundling the font in an application.
